## 🚀 Featured Projects

### 🧾 [Refund Triage Console](https://github.com/hasan-murad02/nysonian-task) &nbsp;·&nbsp; [**Live ↗**](https://nysonian-task.vercel.app)

An internal console that replaces manual Shopify refund handling end to end.
Idempotent webhook ingest, an exactly-once refund ledger, an LLM eligibility
decision grounded in a policy knowledge base, and a review-queue /
reconciliation UI. Ships with architecture diagrams and a written record of the
design trade-offs behind it.

`TypeScript` &nbsp;`Next.js` &nbsp;`LLM / RAG` &nbsp;`Webhooks` &nbsp;`Vercel`

---

### 🧠 [PreMed RAG](https://github.com/hasan-murad02/rag)

A FastAPI retrieval-augmented generation service for answering premed questions.
Builds embeddings with OpenAI `text-embedding-3-large`, stores them in a Qdrant
vector database, and serves queries with similarity-threshold filtering.
Layered project architecture with separated concerns.

`Python` &nbsp;`FastAPI` &nbsp;`OpenAI` &nbsp;`Qdrant` &nbsp;`Vector Search`

---

### 💬 [Chat-App](https://github.com/hasan-murad02/Chat-App)

Real-time chat built on React and Socket.IO — live bidirectional messaging,
client-side routing, and infinite scroll for message history.

`React` &nbsp;`Socket.IO` &nbsp;`React Router` &nbsp;`Bootstrap`

---

### 📰 [NewsALERT](https://github.com/hasan-murad02/NewsALERT)

A news reader front end with a component-driven interface, built on Material UI
and styled-components.

`React` &nbsp;`Material UI` &nbsp;`styled-components`

---

### ✍️ [TextUtils](https://github.com/hasan-murad02/TextUtils)

A text-manipulation toolkit — transform, analyse and clean up text in the
browser, organised as reusable React components with routed views.

`React` &nbsp;`React Router`
